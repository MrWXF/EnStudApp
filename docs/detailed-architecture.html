🏗️ 2. 微服务内部架构（三层架构）

分层职责

Controller 层: 接收 HTTP 请求，参数校验，调用 Service
Service 层: 业务逻辑处理，事务管理，调用 Mapper
Mapper 层: 数据库访问，MyBatis-Plus ORM 操作

🔐 3. 调用链路：用户注册登录

sequenceDiagram participant U as 浏览器 participant N as Nginx:80 participant G as Gateway:8080 participant US as user-service:8081 participant DB as MySQL:13306 participant R as Redis:6379 Note over U,R: 注册流程 U->>N: POST /api/user/register
{username, password, email} N->>G: 转发请求 G->>US: 路由到 user-service US->>US: 参数校验 @Valid US->>DB: 查询用户是否存在 DB-->>US: 返回结果 US->>US: 密码加密 BCrypt US->>DB: INSERT 用户记录 DB-->>US: 返回成功 US-->>G: Result.success() G-->>N: 响应 N-->>U: 注册成功 Note over U,R: 登录流程 U->>N: POST /api/user/login
{username, password} N->>G: 转发请求 G->>US: 路由到 user-service US->>DB: 查询用户信息 DB-->>US: 返回用户数据 US->>US: 密码验证 BCrypt US->>US: 生成 JWT Token US->>R: 存储 Token 缓存 R-->>US: OK US-->>G: Result G-->>N: 响应 N-->>U: 返回 Token Note over U,R: 后续请求认证 U->>N: GET /api/xxx
Header: Authorization: Bearer N->>G: 转发请求 G->>G: JwtAuthFilter 验证 G->>R: 查询 Token 有效性 R-->>G: Token 有效 G->>US: 路由到目标服务 US-->>G: 业务数据 G-->>N: 响应 N-->>U: 返回数据
