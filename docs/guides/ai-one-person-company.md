# AI 一人公司完全指南

> 一个人 + 一组 AI 工具 = 一家能跑通全链路的公司

---

## 一、什么是 AI 一人公司

**核心公式：**

```
1 个人 + 1 组 AI 工具 = 过去 8-10 人团队的产出
```

不是字面意义的"一个人硬扛所有事"，而是 **"碳基智慧（人）+ 硅基执行（AI）"**——人掌握 1% 的灵感和决策，99% 的执行由 AI 完成。

Sam Altman 预言"一人独角兽"时代在 2026-2028 年到来。Carta 数据显示独立创始人创办的新公司占比已达 **36.3%**。

## 五、怎么找客户

### 路径 A：卖产品——内容引流

**核心逻辑**：用户不是来找你的，是来搜问题的。你提供价值 → 他信任你 → 他付费。

#### 方法 1：内容引流（最稳、最持久）

**第一步：选定内容方向**

```
小红书/B站/抖音 内容方向：
├── "每天背 20 个单词，第 N 天——打卡记录"
├── "我用 AI 学英语，3 个月从哑巴到流利对话"
├── "英语写作批改实测对比：AI vs 真人老师"
├── "考研英语 70+ 的路子，我帮你试过了"
└── "这 5 个免费英语 App，我测了一个月，结论在这里"
```

**第二步：每天发一条，至少坚持 30 天**

```
早上 8 点发小红书（通勤流量高峰）
晚上 8 点发 B站/抖音（下班后流量高峰）

每条结尾加一句：
"我把我用的工具整理好了，评论/私信【英语】发给你"
→ 用户私信你 → 你发产品链接 → 转化
```

**真实参考**：英语学习博主，5000 粉丝的小红书号，靠引流到付费社群，月入 2-3 万。

#### 方法 2：平台直接发布

| 平台 | 怎么做 |
|------|--------|
| Product Hunt | 出海发布，获取海外用户 |
| 小众软件 | 投稿，国内早期用户来源 |
| 少数派 | 写"我独立开发了一款英语学习 App" |
| GitHub | 开源部分代码，README 里放产品链接 |
| 即刻 App | 发开发日常，积累关注 |

#### 方法 3：精准投放（花小钱测试）

```
花 200 块测试一条视频
→ 看后台数据：点击率 > 3% 就继续投
→ 加到 500 块 → 加到 2000 块
→ ROI > 1 就放大投放

关键：先拿小钱试，跑通了再加量
```

### 路径 B：接外包——展示能力被动获客

#### 方法 1：平台接单

| 平台 | 适合接什么 | 特点 |
|------|-----------|------|
| 电鸭社区 | 远程外包、整包项目 | 质量较高 |
| 程序员客栈 | 外包项目 | 抽成但稳定 |
| V2EX 酷工作 | 兼职、远程 | 直接对接甲方 |
| 猪八戒/一品威客 | 小项目 | 价格低但门槛低 |
| Upwork | 海外项目 | 赚美金 |

#### 方法 2：写文章被动获客

**让客户主动来找你，而不是你去找客户。**

```
在掘金/思否/知乎/公众号写：
├── "我是怎么一个人用 AI 写完一个全栈 App 的"
├── "Spring Cloud 微服务从 0 到上线，踩坑全记录"
├── "EnStudApp 架构设计详解：6 个微服务怎么拆分"
└── "AI Coding 实战：用 Claude Code 一周开发一个功能"

文章底部放联系方式：
"需要做 Java 后端/全栈开发？微信：xxxxx"
```

**优势**：你有 EnStudApp 这个完整项目作为案例，比大部分接外包的人有说服力。

#### 方法 3：熟人 + 转介绍

```
第 1 步：告诉每个认识的人你在做什么
  "我在做软件外包，Java/全栈都能做，有需要随时找我"

第 2 步：做完一个客户，主动要转介绍
  "如果您的朋友有类似需求，麻烦帮忙推荐，我给您返 10% 介绍费"

第 3 步：维护老客户关系
  每 3 个月发条微信："最近项目还稳定吗？需要帮忙的地方随时说"
```

> **真实规律**：第一个客户最难，后面 80% 的客户来自转介绍。

## 六、怎么定价

> 定价不是算成本，是算"客户愿意付多少钱"。AI 一人公司没有人力成本，定价空间很大。

### 产品定价（SaaS / App 类）

#### 方法 1：对标竞品定价法（最简单）

```
第 1 步：找到 3-5 个竞品，列出它们的价格
第 2 步：取中间值作为你的基准价
第 3 步：刚上线时打 5 折——不是为了低价，是为了让人愿意试

举例：
├── 竞品 A：39 元/月
├── 竞品 B：19 元/月
├── 竞品 C：29 元/月
└── 你：29 元/月（对标 C），首发优惠 15 元/月
```

#### 方法 2：成本倒推法（兜底）

```
问自己：我希望月收入多少？
答：2 万

倒推：
├── 定价 19 元/月 → 需要 1053 个付费用户
├── 定价 29 元/月 → 需要 690 个付费用户
├── 定价 49 元/月 → 需要 408 个付费用户
└── 定价 99 元/月 → 需要 202 个付费用户

结论：定价越高，需要的用户越少，但获取难度越大。
      新手建议从 19-29 元起步，跑通后再提价。
```

#### 方法 3：免费增值模式（产品类首选）

```
免费版：核心功能可用，但有限额
  ├── 目的：降低试用门槛，让用户先进来
  └── 示例：每天学 20 个单词、AI 对话 5 次

付费版：解锁全部功能
  ├── 月付 29 元：打消长期顾虑，随时可退
  ├── 年付 199 元（相当于 16.6 元/月）：锁定长期用户
  └── 终身 499 元：一次性回笼大额资金

转化率参考：免费用户 → 付费用户的转化率通常在 2%-5%
1000 个免费用户 × 3% = 30 个付费用户 × 29 元 = 870 元/月
```

---

### 外包定价（接项目类）

> **核心原则：按项目价值报价，不按工时报价。**

#### 定价公式

```
报价 = 市场价 × 你的效率倍数

市场价参考（2025-2026 国内）：
├── 简单企业官网：5,000 — 2 万
├── 电商小程序：3 万 — 10 万
├── 管理系统/后台：5 万 — 20 万
├── 在线教育/社区 App：10 万 — 50 万
└── 完整平台级项目：30 万 — 100 万+

你的效率倍数 = AI 让你比普通团队快多少
├── 普通团队：3 人 × 3 个月 = 报价 30 万
├── 你 + AI：1 人 × 1 个月 = 还是报价 30 万
└── 为什么？因为客户买的是结果，不是你的工时
```

#### 新手最容易犯的错

| ❌ 错误做法 | ✅ 正确做法 |
|------------|-----------|
| "我算一下要做多少天……" | "这个项目对您的业务价值是多少？" |
| 按天数报价，一天 1000 | 按项目报总价，一口价 |
| 不敢报高价，怕客户跑 | 报低价反而显得不专业 |
| 不签合同就开工 | 签合同 + 50% 预付款再开工 |
| 无限免费修改 | 合同写明：含 2 轮修改，超出另收费 |

#### 新手报价速查表

```
你的水平          │ 项目类型          │ 建议报价
──────────────────────────────────────────────
刚做完第一个项目   │ 简单官网/落地页    │ 3,000 — 8,000
（比如 EnStudApp）│ 带后台的小程序     │ 8,000 — 2 万
                  │ 管理系统           │ 2 万 — 5 万
──────────────────────────────────────────────
有 2-3 个项目经验  │ 电商/社区 App      │ 5 万 — 15 万
                  │ 完整平台           │ 15 万 — 30 万
──────────────────────────────────────────────
有行业口碑        │ 企业级系统         │ 30 万+
```

> **一句定价心法**：客户说"太贵了"往往不是真的贵，是没看到值在哪。给他看你的项目（EnStudApp），告诉他"我做过一模一样的"，价格就不是问题了。

## 七、我技术不够怎么办

> 在 AI 时代，"技术不够"已经不是障碍了。关键是你会不会用 AI 补齐短板。

### 心态先行：你不需要什么都会

```
传统程序员的困境：
"我不会前端" → 不敢接全栈项目
"我不会部署" → 不敢接外包
"我不会设计" → App 做得丑没人用

AI 时代的答案：
"我不会前端" → Claude 帮我写 React 页面
"我不会部署" → Claude 帮我配 Docker + Nginx
"我不会设计" → Midjourney 出图 + 参考竞品抄
```

**你只需要三样东西：**
1. 能判断好坏的**审美和逻辑**
2. 能把需求说清楚的**表达能力**
3. 愿意反复调试的**耐心**

剩下的，AI 帮你补齐。

---

### 场景一："我只会后端，不会前端"

**现在的做法：**

```
第 1 步：告诉 AI
  "我要做一个登录页面，用 React + Ant Design，
   有手机号+验证码登录和密码登录两种方式"

第 2 步：AI 给你写好完整的组件代码
  ├── LoginPage.tsx（页面）
  ├── api/login.ts（接口调用）
  └── store/userStore.ts（状态管理）

第 3 步：你只需要
  ├── 打开浏览器看效果
  ├── 告诉 AI "按钮颜色改蓝一点"
  ├── 告诉 AI "加载时加个 loading 动画"
  └── 反复几轮，页面就做好了
```

你不需要学 React 原理，你只需要能描述"我要什么样子"。

### 场景二："我没做过微服务，不敢碰"

**你现在的 EnStudApp 就是答案：**

你之前可能也没完整做过 Spring Cloud 微服务，但 AI 帮你：

- 写了 6 个微服务的完整代码

**不是你变厉害了，是你学会了让 AI 替你厉害。**

## 八、从哪一步开始

> 很多人卡在"想太多，动太少"。这里给一条最简路径，每一步都有明确标准。

### 总览：四阶段路线图

```
阶段一：做出东西（第 1-2 周）
  → 目标：有一个能打开演示的项目

阶段二：让人看到（第 3-4 周）
  → 目标：有 100 个人知道你在做什么

阶段三：收到第一笔钱（第 2-3 个月）
  → 目标：收到第一个客户的钱，哪怕只有 1 块钱

阶段四：复制放大（第 4-6 个月）
  → 目标：跑通从获客到交付的全流程，重复操作
```

---

### 阶段一：做出东西（第 1-2 周）

**你现在已经在做！EnStudApp 就是你的第一个东西。**

你需要确认的：

```
□ 你的项目代码在 GitHub 上公开可见
□ README 里有截图和使用说明
□ 别人能看懂这个项目是干嘛的
```

如果还没做到，这周完成。不要追求完美——**完成比完美重要 100 倍。**

---

### 阶段二：让人看到（第 3-4 周）

**这是最关键也最容易被跳过的一步。** 很多人做完了东西就等着天上掉用户，结果什么都没发生。

#### 第 1 天：整理你的"作品卡"

```
在 GitHub 项目 README 里加：
├── 3-5 张产品截图（登录/首页/核心功能）
├── 一句话说清楚是干嘛的
├── 用了什么技术（显得专业）
└── 你的联系方式（微信/邮箱）
```

#### 第 2-3 天：写第一篇文章

```
标题："我用 AI 辅助开发，一个人写完了 1.2 万行代码的英语学习 App"
内容：讲讲你做这个项目的经历和心得
重点：不要写成技术文档，要写成故事

发布到：
├── 掘金（技术社区）
├── V2EX — "分享创造"节点
├── 即刻 — 带上 #独立开发者 标签
└── 知乎 — "独立开发者"话题
```

#### 第 4-7 天：把文章拆成短视频/图文

```
从文章里拆出 5-7 条短内容：
├── 小红书："一个人开发 App 的第 N 天"
├── 抖音/B站："0 基础用 AI 写代码 2 周做出 App"
├── 朋友圈："最近用 AI 做了一个小项目，欢迎围观"
└── 即刻：每天发一条开发日常
```

#### 第 7-14 天：持续发，看数据

```
每条发出去，看三个指标：
├── 阅读/播放量：多少人看到了
├── 互动数（点赞/评论/收藏）：多少人感兴趣
└── 私信数：多少人主动联系你

📌 哪个平台数据好，下一步就重点做哪个平台
```

---

### 阶段三：收到第一笔钱（第 2-3 个月）

#### 路线 A：卖产品

```
第 1 步：产品加付费功能
  ├── 支付宝/微信支付接入（用第三方 SDK，2-3 天）
  └── 免费试用 7 天，到期自动提醒付费

第 2 步：把你的粉丝/读者转化为用户
  ├── 私信你的人 → 发产品链接 + 优惠码
  ├── 文章底部 → 放产品地址
  └── 朋友圈 → "内测邀请，前 100 名免费"

第 3 步：收到第一个付费用户
  └── 哪怕只收了 1 块钱，你也跑通了闭环
```

#### 路线 B：接外包

```
第 1 步：把你的项目做成"接单名片"
  ├── 在接单平台注册（程序员客栈/电鸭/Upwork）
  └── 个人介绍里放 EnStudApp 链接 + 截图

第 2 步：主动联系潜在客户
  ├── 在 V2EX/即刻搜索"需要开发""外包""找人"等关键词
  └── 看到需求 → 私信："这个我能做，这是我的项目（附链接）"

第 3 步：谈下第一个项目
  ├── 报价参考第六章的速查表
  ├── 签合同 + 收 50% 预付款
  └── 哪怕只有 3000 块，你也从"学习者"变成了"服务商"
```

---

### 阶段四：复制放大（第 4-6 个月）
