## 🏗️ 微服务内部架构（三层架构）

```
┌─────────────────────────────────────────────────────────────┐
│  Controller 层 - API 入口                                    │
│  • RestController (@Tag @Operation)                         │
│  • 参数校验 (@Valid @RequestBody)                           │
│  • 统一响应 (Result<T>)                                     │
└─────────────────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────────┐
│  Service 层 - 业务逻辑                                       │
│  • 业务接口 (XxxService)                                    │
│  • 业务实现 (XxxServiceImpl)                                │
│  • 事务管理 (@Transactional)                                │
│  • 业务异常 (BusinessException)                             │
└─────────────────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────────┐
│  Mapper 层 - 数据访问                                        │
│  • MyBatis-Plus (BaseMapper<T>)                             │
│  • 自定义 SQL (@Select @Update)                             │
│  • 分页查询 (PageResult<T>)                                 │
└─────────────────────────────────────────────────────────────┘
```

**编码规范：**
- ✅ 依赖注入：`@RequiredArgsConstructor` + `private final`
- ✅ 统一响应：`Result<T>`，成功码 `0`
- ✅ 分页：`PageResult<T>` 游标分页
- ✅ DTO 校验：Java Record + Jakarta Validation
- ✅ 异常处理：`BusinessException` + `GlobalExceptionHandler`

## 🔐 调用链路 1：用户注册登录

### 注册流程
```
浏览器 → Nginx → Gateway → user-service → MySQL
                              ↓
                        参数校验 @Valid
                              ↓
                        查询用户是否存在
                              ↓
                        密码加密 BCrypt
                              ↓
                        INSERT 用户记录
                              ↓
                        返回成功
```

### 登录流程
```
浏览器 → Nginx → Gateway → user-service → MySQL
                              ↓
                        查询用户信息
                              ↓
                        密码验证 BCrypt
                              ↓
                        生成 JWT Token
                              ↓
                        存储 Token 到 Redis
                              ↓
                        返回 LoginResultDTO
```

### 后续请求认证
```
浏览器 (Authorization: Bearer <token>)
   ↓
Nginx
   ↓
Gateway (JwtAuthFilter 验证)
   ↓
Redis (查询 Token 有效性)
   ↓
目标微服务
   ↓
返回业务数据
```

## 🤖 调用链路 2：AI 对话

```
浏览器 → Nginx → Gateway → chat-service → MySQL (查询会话)
                              ↓
                        Redis (获取上下文)
                              ↓
                        构建 Prompt
                        • 系统提示词
                        • 历史消息
                        • 用户输入
                              ↓
                        DeepSeek API (POST /chat/completions)
                              ↓
                        接收 AI 回复
                              ↓
                        MySQL (保存消息)
                              ↓
                        Redis (更新缓存)
                              ↓
                        语法纠正分析（可选）
                              ↓
                        返回 ChatResponse
```

**详细流程：**
1. 用户发送消息
2. Gateway JWT 认证
3. 查询会话信息
4. 获取历史上下文
5. 构建 Prompt
6. 调用 DeepSeek API
7. 保存对话记录
8. 更新缓存
9. 返回 AI 回复 + 语法建议

## 📚 调用链路 3：单词学习

```
浏览器 → Nginx → Gateway → word-service → MySQL (查询单词)
                              ↓
                        记忆算法计算
                        • 艾宾浩斯遗忘曲线
                        • 计算下次复习时间
                              ↓
                        MySQL (更新学习记录)
                              ↓
                        MySQL (更新记忆状态)
                              ↓
                        Redis (更新统计缓存)
                              ↓
                        判断是否掌握
                        • 连续正确 >= 阈值
                              ↓
                        返回 LearnResult
```

**获取今日学习任务：**
```
浏览器 → Gateway → word-service → Redis (查询缓存)
                                        ↓
                                  缓存未命中
                                        ↓
                                  MySQL (查询待复习单词)
                                        ↓
                                  更新缓存
                                        ↓
                                  返回 TodayWords
```

## ✍️ 调用链路 4：写作批改

```
浏览器 → Nginx → Gateway → writing-service → MySQL (保存作文)
                              ↓
                        构建批改 Prompt
                        • 评分维度：
                          - 语法
                          - 词汇
                          - 结构
                          - 内容
                          - 逻辑
                              ↓
                        DeepSeek API (作文批改)
                              ↓
                        解析批改结果 JSON
                        • 总体评分
                        • 语法错误
                        • 改进建议
                        • 优秀表达
                              ↓
                        MySQL (保存批改结果)
                              ↓
                        返回 CorrectionResult
```

## 💾 核心数据流向

### 写入流程
```
HTTP 请求 → Gateway → 微服务 → Redis 缓存
                         ↓
                    MySQL 数据库
```

### 读取流程（Cache-Aside）
```
HTTP 请求 → Gateway → 微服务 → 查询 Redis
                              ↓
                        {缓存命中?}
                         /        \
                       是          否
                       ↓           ↓
                  返回数据    查询 MySQL
                                ↓
                           更新缓存
                                ↓
                           返回数据
```

### 异步流程（消息队列）
```
微服务 A → 发布事件 → RocketMQ → 消费事件 → 微服务 B
```
