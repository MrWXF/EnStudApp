## 核心流程

### 1. 用户请求流程
```
浏览器 → Nginx(:80) → Gateway(:8080) → [微服务] → MySQL/Redis
```

### 2. 服务注册流程
```
微服务启动 → 注册到 Nacos → Gateway 发现服务 → 路由转发
```

### 3. AI 对话流程
```
用户 → Gateway → chat-service → DeepSeek API → 返回 AI 回复
```
